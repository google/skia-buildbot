Skia Perf anomaly insights for AI agents

A small, read-only API that lets LLM agents find, summarize and explain performance anomalies (regressions and improvements) detected by Skia Perf, chart their traces, propose how to triage them, and check whether a commit caused any. The same operations are available over MCP and REST.

Connect an agent

Gemini CLI

Add to ~/.gemini/settings.json:

{
  "mcpServers": {
    "perfinsights": {
      "httpUrl": "{{.MCPURL}}"
    }
  }
}

Jetski

Add to ~/.gemini/config/mcp_config.json:

{
  "mcpServers": {
    "perfinsights": {
      "url": "{{.MCPURL}}"
    }
  }
}

curl

Or call the REST API directly:

curl -s '{{.PublicURL}}/api/v1/sheriffs'
curl -s '{{.PublicURL}}/api/v1/insights:summarize?sheriff=NAME&days=7'
curl -s '{{.PublicURL}}/api/v1/insights:suggestTriage?sheriff=NAME&days=1'
curl -s '{{.PublicURL}}/api/v1/anomalies/ID/trace?commits_before=100'
